---

Delete a transaction in Budget App when you logged it twice or added it to the wrong budget. The amount is added back to the budget's remaining balance.

<Warning>
  Deleting a transaction is permanent and cannot be undone.
</Warning>

<Steps>
  <Step title="Open the budget">
    On the **Dashboard**, select the budget that contains the transaction.
  </Step>
  <Step title="Select the transaction">
    In the transaction list, select the transaction you want to remove.
  </Step>
  <Step title="Select Delete">
    Select **Delete transaction**.
  </Step>
  <Step title="Confirm">
    In the confirmation dialog, select **Delete**.
  </Step>
</Steps>

## Result

The transaction is removed from the list and the budget's remaining balance increases by its amount.

<Tip>
  Added a transaction to the wrong budget? Delete it, then [add it again](/transactions/add) to the correct budget.
</Tip>
