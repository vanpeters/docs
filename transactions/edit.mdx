Edit a transaction in Budget App when you entered the wrong amount or date, or want to add a note. The budget's remaining balance updates as soon as you save.

<Steps>
  <Step title="Open the budget">
    On the **Dashboard**, select the budget that contains the transaction.
  </Step>
  <Step title="Select the transaction">
    In the transaction list, select the transaction you want to change.
  </Step>
  <Step title="Update the details">
    Change the **Amount**, **Date**, or **Note**.
  </Step>
  <Step title="Save">
    Select **Save**.
  </Step>
</Steps>

## Result

The transaction shows the new details and the budget balance is recalculated.
